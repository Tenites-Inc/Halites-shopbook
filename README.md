# ShopBook by Halites

- **Live demo** (sample data): https://tenites-inc.github.io/Halites-shopbook/
  Switch **Trade** on the Shop side to see all eight packs: provisions shop,
  wholesaler, building materials, cooking gas, restaurant, pharmacy, petrol
  station and beauty salon. Each pack is built around a problem only that
  trade has; the core (stock, owner PIN, approvals, pay-later book, payments)
  is shared.
- **MVP proposal (PDF):** https://tenites-inc.github.io/Halites-shopbook/ShopBook_by_Halites_MVP_Proposal.pdf

Everything here is public. The demo uses invented shops, people and figures.
